# 0006 — 文件夹作用域记忆（单根 + 祖先继承）

## 状态

已采用并实现（本地隔离验收）。用户授权按合理方式继续后，明确采用字符集 A、缺失 inherit 保留 path、根内符号链接按真实路径解析。真实项目与真实模型的续接质量仍未验证。

## 背景

v2 当前的项目边界由最近的 `.pi-root` 决定，一个项目只有一份 `.pi-memory`。知识记录按 kind 平铺在 `knowledge/<kind>/`，路径不参与归属、检索或上下文选择；工作记录同样只有一份 overview/state。

计算化学工作的实际结构是同一项目根下多个计算目录，例如 `01-opt/`、`02-neb/`、`03-freq/`。方法、软件版本和体系信息需要跨目录共享；运行身份、结果和诊断只对所属目录及其子目录有效。

若要求每个目录独立创建 `.pi-root`，共享信息会被割裂，跨目录检索与继承只能人工复制；若继续保持全局平铺，兄弟目录的运行、能量和诊断会互相污染上下文。M4 已多次发现同类串线缺陷（同名体系、活动 run 隔离），说明仅靠检索排序不足以表达目录归属。

## 决策

1. 项目根仍由最近的 `.pi-root` 决定。新增目录不会自动创建标记或嵌套项目；`initializeV2(..., {nested:true})` 保留为显式选项，不是默认路径。
2. 知识记录增加可选字段 `scope`：
   - 形状为 `{path, inherit}`，`path` 是相对项目根的 POSIX 路径，根目录为 `"."`。
   - 新记录的默认 `path` 由当前工作目录的真实路径计算，不猜测目录；显式 folder/entry.scope 允许选择历史目录。禁止绝对路径、`..`、反斜杠、控制字符和越界段。根内符号链接取真实路径；根外链接拒绝，历史目录也校验最近现存祖先。字符集采用 A：允许内部空格、中文与常见标点，不规范化大小写或 Unicode。
   - `inherit` 默认 `true`：祖先目录可见；`false` 表示仅本目录可见。
   - 消费时缺失 `scope` 一律视为 `{path: ".", inherit: true}`；仅缺失 inherit 时保留原 path、补 true。不可变旧记录与底层原始字段不回写；修订默认保留原 scope。
3. `schemaVersion` 保持 2，不迁移、不改写既有记录，不重命名历史目录。作用域是附加维度，不是新存储层。
4. 召回默认取当前目录的祖先链（根 → … → 当前目录）。兄弟目录默认排除，仅显式 `allFolders` 时纳入。实体引用、运行身份仍按现有全局规则解析。
5. 权威存储仍是 `.internal/records` 下的不可变记录。目录页与目录索引是派生视图，可删除重建，不构成第二套事实库，也不参与 grounding。
6. 目录重命名或移动后，旧记录的作用域保持原字符串。不静默改写、不按名称相似度猜测新位置；显式迁移命令留到 M7。
7. `.pi-root` 仍是启用记忆的必要条件；作用域不改变标记语义，也不提供跨根检索。

## 后果

正面：

- 一个项目内共享方法与软件信息，目录级运行与结果互不污染。
- 不新增标记、不复制记录、不改变现有写入原子性与账本校验。
- 旧记录、旧配置和现有 CLI/工具参数保持可读，无需迁移窗口。

负面：

- 目录改名或移动会造成作用域陈旧，召回静默变少；只能显式修复。
- 路径规范化必须与真实文件系统一致（大小写、Unicode 形式），不能靠字符串清洗。
- 上下文预算需要在"当前目录 → 祖先 → 全局"之间分配，简报长度受限。
- 跨根（不同 `.pi-root`）仍不可见，用户需要自行决定项目边界。

## 替代方案

- 每目录一个 `.pi-root`：隔离强，但共享信息重复，跨目录检索失效；作为显式选项保留，不做默认。
- 仅全局平铺：现状；无法防止兄弟目录串线，不满足需求。
- 记录直接存绝对输出路径并据此召回：计算目录常被移动或清理，绝对路径会大面积失效；且违反项目相对定位约束。
- 引入工作区/多根索引：超出当前范围，与"无服务端、无中央库"的目标冲突。

## 验证（M5 本地隔离）

- 作用域解析、越界、符号链接、旧记录默认值与账本篡改。
- 祖先可见、兄弟排除、`inherit:false`、`allFolders` 及排序。
- 上下文与简报的目录过滤、预算和显式省略。
- 目录页生成、重建、手工修改冲突。
- 计算化学纵向：根方法 + 两个运行目录，结果与诊断不串线。

上述契约由 M5 定向测试覆盖，实际命令与结果见 [测试报告](../testing.md)。不从合成夹具外推真实模型选择、真实项目续接或科学有效性。目录迁移与整理仍留到 M7。
