# 0007 — 可选计算化学卡片与固定来源

## 状态

已采用，用户已确认设计并授权开发。M6 采用分阶段失败测试、最小实现和本地隔离回归；实际命令与结果见 [测试报告](../testing.md)，字段和使用契约见 [M6 卡片](../next/m6-cards.md)。本决策不是科学有效性或真实模型质量认证。

## 背景

自由文本和已有 run/result 结构能够保留声明，但不足以稳定表达未知、字段来源、适用限制、来源修订及同性质冲突。只美化 Markdown 会掩盖信息缺失；重新发明运行/结果模型则会产生相互分歧的权威字段。

## 决策

1. 新增可选 entry.card，card.version=1，schemaVersion 保持 2。旧记录不补字段、不回写、不迁移；保证新代码读旧数据，不保证旧代码读新卡片。未知卡片版本拒绝。
2. 仅 systems/methods/runs/results/diagnostics 提供卡片。known/unknown/not-applicable 区分值、未知原因和不适用依据。零、false、缺失、null 不互换，不推断默认单位、科学参数或成功状态。
3. 已知字段保留来源定位符、原文和来源类别；来源定位符须属于 entry.evidence。校验不访问定位文件、不证实引文真实性。审核、正常结束、出处和字段 known 均不等于科学认证。
4. entry.run 仍是四轴和运行位置的唯一权威；entry.result 仍是数值、单位、定义和 runId 的唯一权威。卡片 support 引用这些字段的来源，不重复保存其值。
5. 复用既有实体 ID 与不可变修订，固定引用为 {id, revision}。检查实际修订、kind、自引用和必要的实体一致性。来源后续更新不回写结果、不替换固定修订、不消除原限制。
6. 同 run 同性质冲突在项目共享锁内对全局 current 记录检查，不受目录召回过滤影响。单位不分裂身份，不进行同义词推断或单位转换；旧结果缺限定信息时保守处理。旧重复历史保持可读，但新增或激活不能继续扩大冲突。
7. 显式替代复用原 ID 的 revise + expectedRevision，不新增跨记录替代图。已有结果卡不能换 run/性质身份；卡片不能通过省略字段降级。requestId 重试和并发保护继续生效。
8. 自动提炼仍只选择摘录；候选不能携带卡片，也不能覆盖已有卡片。显式 API/CLI/工具写入经过同一存储校验链；人工或 auto approve 不升级来源或科学含义。
9. 卡片页面和搜索/目录/简报为派生参考，不参与 grounding。旧 JSON+文本生成页继续精确识别；手改拒绝覆盖。静态页面显示固定来源状态，搜索/目录/简报可提示来源更新；结果卡的 resultRun 指固定来源，最新状态另置 sourceRun.latestRun。无卡片旧记录的 resultRun 语义不变。
10. 保留 M5 目录隔离、显式实体例外、首轮简报不超过 1200 字符及上下文不超过 12000 字符。卡片不授权计算、提交、重跑或跨项目读取。

## 后果与限制

- 结构化约束可在发布前拒绝缺失条件、错误引用、冲突和隐式降级，并保留不可变历史。
- 新卡片写入后不能承诺旧版本插件可读；降级和迁移另议，不自动处理。
- 字符串性质身份不能识别所有科学等价关系；有定位符和引文也不能证明字段科学正确。
- 为防止半成品进入账本，结构模块先独立测试，待条件、引用、冲突和候选保护具备后才接入发布。
- TypeBox 工具结构由同一字段/类型表生成；跨字段、来源归属、固定引用和冲突仍由存储裁决。
- 本地适配器测试使用宿主 TypeBox 和隔离扩展副本，不等于真实 Pi 会话逐卡片交互验收。离线宿主回归、合成纵向、真实模型选择和人工科学审阅分层报告。
- 不提前实现 M7 自动整理/迁移或 M8 发布，不改变 v1、默认入口、版本或打包字段。
