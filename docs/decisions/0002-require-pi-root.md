# 0002 — 最近的 .pi-root 定义记忆项目边界

状态：保留。当前实现为 `src/memory.mjs`；详细接口与存储格式以 README 为准。

从真实 cwd 向上查找最近的 `.pi-root` 普通文件，它定义唯一项目根。没有标记时不读记忆、不查注册表、不注入上下文。Git 根、旧配置和全局设置均不能代替标记。

只有用户显式 `/memory-init` 或 CLI `init` 可以创建标记和隔离的新存储。普通启动与自动上下文读取不创建文件。子目录沿用最近根；嵌套标记建立独立项目。每次读写重新校验根和身份，标记撤销或切换后旧句柄失效。

当前版本只读取 `.pi-memory-local/`。旧配置与笔记路径只检测名称并说明，不自动接管、迁移、覆盖或删除。会话历史中的内容不被追溯擦除。没有项目外记忆、文件夹继承、全局注册表或跨项目召回。

测试见 `test/memory.test.mjs` 与 `test/extension.test.mjs`，覆盖最近根、撤销、复制后独立读写、项目切换与旧数据保护。
