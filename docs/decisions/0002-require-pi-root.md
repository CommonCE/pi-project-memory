# 0002 — 没有 .pi-root 就不使用记忆

状态：已实现于 0.1.1；覆盖 0001 中的自动边界规则。[0003 — 学习、审核与交接](0003-learning-review-handoff-init.md) 在 0.2.0 增加用户显式 `/memory-init` / CLI setup 标记创建入口；普通启动和自动流程依然不能创建标记。以下保留 0.1.1 历史决策。

## 用户要求

严格保留旧 bashrc 包装的显式启用策略：没有 `.pi-root` 就不使用记忆。仅有 git 仓库、项目 JSON、已有注册记录或全局启用设置均不足以启用。

## 决策

- 从真实 cwd 向上查找最近的 `.pi-root` **文件**；它定义唯一自动项目根。
- 没有标记时返回 `NO-MEMORY`，不读注册表、项目 JSON 或笔记，不自动注入；检索为空；初始化、接入、保存、项目列表和手动选择被拒绝。
- 不自动创建标记。新项目由用户手动创建 `.pi-root` 再初始化。
- 嵌套 git 仓库或 JSON 不改变项目归属；嵌套标记才建立边界。
- 手动选择无法绕过当前 cwd 的标记条件；目标根也必须保留标记。
- 每次读写重新校验标记；删除或改变最近标记会撤销旧句柄的访问。已存在于会话历史中的内容不被追溯清除。
- 不修改 bashrc、旧配置、旧记忆或真实用户注册表。

## 验证

语法检查与 24 项测试，包括无标记的 git/config/registry 不能启用、畸形注册表不被读取、手动选择不能绕过、删除标记后撤销访问、CLI 拒绝写入及本机 Pi Jiti/TypeBox 扩展测试。全部使用临时目录，无模型调用。
