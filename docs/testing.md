# 测试说明

测试只保护当前状态、笔记、检索和入口的现行契约，不继续维护已删除的候选审核、事件投影、科研卡片或阶段验收矩阵。旧合成评测与宿主离线 provider 已随被替代机制移除。

## 命令与范围

```bash
npm run check
node --test test/memory.test.mjs
PI_TEST_HOST_PACKAGE=/absolute/path/to/pi-coding-agent/package.json npm test
```

`memory.test.mjs` 使用新建临时目录，覆盖新进程恢复当前任务、阻塞、重要文件和下一步，最近项目标记隔离，旧数据原样保留，纠正与撤回，失效/未核实默认排除，手工修改的哈希冲突，写入故障、并发和进程中断，路径逃逸与坏格式，长度上限和本地稀疏向量检索。

写入保护通过真实子进程竞争与中断，以及定点文件系统故障注入验证。另有回归测试确认手工添加 UTF-8 BOM 会改变整文件哈希，以及 CLI 遇到非法 UTF-8 输入会报错、不写入笔记。上下文测试要求笔记正文完整包含或整条省略，防止丢掉中间的科学限定条件。科学文本是固定夹具，不是计算结果。

`extension.test.mjs` 通过调用者指定的已安装 Pi 的 Jiti、TypeBox 和导出 API 加载真实 `index.ts`，以最小模拟事件上下文验证：工具/命令注册、每次模型调用前刷新、纠正后旧上下文移除、撤回排除、项目切换和损坏文件诊断。使用宿主实际文件变更队列。未提供 `PI_TEST_HOST_PACKAGE` 时明确跳过。
