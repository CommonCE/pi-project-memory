# 下一版开发入口

本目录记录面向科研计算、软件开发和集群操作的项目记忆设计与实现。**当前主线仍是“记住—找回—继续—纠正”，长期方向是项目优先、证据可追溯、保守准入的分层记忆。** M1–M3 已实现，M4 冻结在离线契约，M5/M6 已完成本地契约验收，M7 仅完成共享手动简报入口与 CLI。当前先完成 M7，再做小规模使用验收，之后按真实缺口完善长期治理与 consolidation；Global、embedding 和 Skill 提升后置。默认入口仍是 v1，新版显式加载 v2.ts，两套扩展不同时加载。

## 阅读顺序与文档职责

1. [总体架构与项目盘点](architecture.md)：目标分层、生命周期、召回职责、已有成果和差距；目标设计不等于已实现能力。
2. [当前路线图](roadmap-v2.md)：唯一的开发优先级入口；P0 收尾 M7 → P1 使用验收 → P2 治理 → P3 召回 → P4 可选跨项目提升。
3. [M7 最小计划](m7-plan.md)：当前可执行切片，下一步是 Pi 手动简报接入；不扩大到整理系统。
4. 相关阶段契约与 [测试报告](../testing.md)：按当前任务定点读取，不把历史交接提示词当作当前待办。

架构整理不改变既有接口、存储或默认行为；真实使用质量仍未验证。

## 已确认的方向

- 记忆默认位于当前项目目录；初始化目录成为项目根，子目录沿用最近的 `.pi-root`。
- 不要求兼容旧 pack、旧候选和旧配置；旧数据不自动迁移或删除。
- 面向计算化学及相关软件开发，兼顾近期工作续接与长期知识。
- 可以舍弃旧提交历史，但本阶段不创建提交、推送、强推、删除仓库或改可见性。
- 当前未提交的 profile 初始化改动保留，不为设计工作撤销。

## 本阶段产物与限制

第一步完成设计、上游对比和公开前初步审计；随后实现 M1 显式存储、M2 工作记忆，以及 M3 宿主提炼、候选审核和实体召回。
没有扫描真实计算目录、旧记忆或完整用户会话；M4 经独立授权完成 5 次固定合成材料的真实模型选择小样本，结果与限制见目标文档。宿主验证仍只使用本地确定性 provider。
对比上游只下载公共源码到临时目录，不安装、不执行上游代码。
公开审计是本地可达历史的启发式检查，不构成“可以安全转公开”的保证。

M3 功能闭环已完成，生产默认 review，学习模型使用当前宿主模型；已完成的 M3 宿主验证仅调用本地确定性 provider。M4 已冻结在“离线契约完成、真实质量未验证”的状态。M5 已按 [ADR 0006](../decisions/0006-folder-scoped-memory.md)、M6 已按 [卡片契约](m6-cards.md) 完成本地隔离验收。先收尾 M7，再按路线图安排使用验收与治理；真实模型、真实项目和发布分别授权，M8 保留为独立质量/发布支线，不要求所有未来治理功能先完成。不继续展开旧迁移设计，也不涉及 Git 历史替换。
