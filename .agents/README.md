# .agents — 项目内开发规则

存放 pi-project-memory 的开发规则与可复用提示词，随仓库提交。不是运行时配置，
不参与插件加载，也不存放记忆数据、测试输出或计算产物。

## 文件

| 文件 | 用途 |
|---|---|
| [DEVELOPMENT.md](DEVELOPMENT.md) | 详细开发规则：单次/累计预算、探索停止条件、长对话交接、架构契约、验证分级 |

根目录 [AGENTS.md](../AGENTS.md) 是 Pi 自动加载的入口，只放硬性上限与指向这里的链接。
规划中的任务模板可以放在 `.agents/prompts/`，但**目前没有**该目录。

## 使用方式

- Pi 会自动加载 `AGENTS.md`（以及各级父目录的同名文件），**不会**自动加载本目录内容。
  需要详细规则时显式引用，例如：

  > 读 `AGENTS.md` 与 `.agents/DEVELOPMENT.md`，只改 `src/v2-working.mjs` 的状态刷新逻辑，
  > 保持现有 CLI/工具契约，不要提交。

- `.agents/skills/` 是 Pi 会发现的技能目录；本仓库目前没有技能，不要把它当规则目录使用。
- 规则不扩大授权：`.agents/` 里写的要求仍然服从当次用户的明确指令。

## 维护

- 上下文预算改动时同步根 `AGENTS.md`：单次读取 200 行 / 8 KB；单条 bash 输出 80 行 / 8 KB；
  每轮探索 24 KB / 8 个文件；每 3 次探索调用检查停止条件；交接最多 30 行。
  均为代理行为约束，不是 Pi 运行时配置；不修改全局设置，也不会清理既有会话上下文。
- 已知大文件清单用 `find . -type f -printf '%s %p\n' | sort -rn | head` 重新测量后更新。
- 只写可复用的规则：不写密钥、个人数据、原始对话、大段日志或临时结论。
- 已实现的契约以代码、测试和 `docs/decisions/` 为准；本目录描述与之冲突时，先改这里。
